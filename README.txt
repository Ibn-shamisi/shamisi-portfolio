SHAMISI PORTFOLIO (independent, no Python needed)
- Double-click index.html to view it.
- To put it online: upload this whole folder to any host (Netlify Drop, GitHub Pages, or your Truehost public_html/portfolio).
- To show your books: open script.js and add them to the BOOKS list at the top.
- Buttons link to your live shop at https://shamisipublishers.co.ke
